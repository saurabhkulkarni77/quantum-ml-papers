An executed, Colab-ready notebook — [`Quantum_Models_from_Papers.ipynb`](Quantum_Models_from_Papers.ipynb) — that implements the quantum models of two published papers, with classical baselines, and compares the reproduction against each paper's reported numbers.

## Headline results (from the executed notebook)

**Paper A** — test RMSE, Pb-BTC MOF, paper protocol (400 train / 100 test):

| Model | Paper | This notebook |
|---|---|---|
| QCNN (99 params) | ≈ 0.04 eV/atom | 0.0450 eV/atom |
| QDNN (63 params) | ≈ 0.04 eV/atom | 0.0404 eV/atom |
| Ridge regression (classical baseline) | — | 0.0354 eV/atom |
| Shallow MLP (classical baseline) | — | 0.3822 eV/atom |

**Paper B** — success ratio at m = 1800 (20 runs; fraction that found the brute-force optimum), weighted-sum formulation:

| Method | Paper | This notebook |
|---|---|---|
| FM-QUBO | 0.80 | 0.95 |
| BOCS-QUBO | 0.55 | 0.55 |
| Random search | — | 0.00 |

For the ε-constraint formulation the paper reports > 0.80 for FM-QUBO; on this reproduction's stand-in plate model FM-QUBO reached 0.10 — a divergence reported plainly in the notebook (§B.4).

## Data provenance

- **Paper A** uses the paper authors' own public demo data ([Hsu-Kai/qcnn-energy-demo](https://github.com/Hsu-Kai/qcnn-energy-demo)): 1,219 DFT-labelled Pb-BTC MOF structures (`PbMOF.db`) and their precomputed bispectrum descriptors, used unchanged. The paper's alloy dataset is *not* public (per the paper's data-availability statement), so the alloy system is not reproduced.
- **Paper B** has no external dataset: the paper's data are generated by its CalculiX FEM analysis, whose exact dimensions/materials are in the paper's supplementary file. The notebook therefore generates its data with a **simplified plate modal model, clearly labelled as a stand-in**; absolute frequencies differ from the paper's by construction, and the reproduced result is the algorithm comparison (success ratios) under the paper's protocol.

## How to run

Click the Colab badge above → **Runtime → Run all**. CPU runtime only (statevector simulators; no quantum hardware calls). The first code cell installs pinned dependencies. A full run takes roughly **1.5 hours**, dominated by Paper B's 20-run optimization benchmarks, which follow the paper's protocol. The saved notebook already contains the outputs of a complete execution.

## Limitations (also stated in the notebook)

- Paper A's alloy system is not reproduced (data not public); its QDNN is an honest reconstruction at the paper's parameter count (the gate layout is in the paper's Supplemental Material); training is 300 epochs vs the demo's 1000, on a single split.
- Paper B's physics is a stand-in plate model, not the paper's CalculiX FEM; D-Wave quantum annealing (used in the paper alongside simulated annealing) is omitted; BOCS uses a simplified Gaussian-posterior sampler.
